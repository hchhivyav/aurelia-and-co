# Aurelia & Co. — Luxury Jewelry Store

A responsive jewelry e-commerce website built with Next.js, React, TypeScript, and Tailwind CSS.

## Features
- Product catalog and detail pages
- 10 sample jewelry products
- Add to cart and cart management
- Checkout form and demo order
- Printable HTML invoice
- Responsive design

## Technologies
- Next.js 14
- React 18 and TypeScript
- Tailwind CSS
- Framer Motion

## SSR and SSG
- **SSG:** Pre-generates suitable pages, including product pages.
- **Client-side rendering:** Handles cart and checkout interactions.

## Run Locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Check the project:

```bash
npm run typecheck
npm run build
```
